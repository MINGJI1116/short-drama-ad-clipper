# 海外短剧投流素材剪辑工作流（拼接为主 · 就地修补 SOP）

> 适用范围：SODA TV 类海外短剧（英语/小语种）投流素材制作。
> 本流程由 2026-11-13《假离婚真后悔》(OAEN2457) 与《Pregnant by My Husband's Friend》两个实战项目复盘提炼，全部规则经用户逐条确认，全部步骤已经过验证。
> 配套规范：《投流素材培训（202606）》→ 速查见 `spec.md`。

---

## 〇、流程总览

```
素材接收 → 勘察建档 → 规范确认(一次问齐) → 选段规划(全局去重+每集覆盖)
    → 元素制作 → TTS 配音 → ffmpeg 批量构建 → 五维质检 → 命名交付
```

核心原则（血泪教训总结）：

1. **选段全局唯一**：多条素材共享一个素材池时，任何一段画面只允许出现在一条素材里；
2. **切点吸附镜头边界**：跳剪必须在镜头切换处下刀，严禁在镜头中间跳；
3. **解说逐句对位**：每句解说配一个专属选段，从它描述的场景起点开始播；
4. **音轨只留主角**：解说版只有「解说 + BGM」两个层次，原片对白要么去掉、要么压到 0.15 以下；
5. **先审计后编码**：选段表必须程序化审计（0 重叠 + 每集覆盖）通过后再开渲染；
6. **单条时长约 2 分钟**：每条素材（正片 + 落版）目标 ≈117–125s；
7. **解说密度必须够**：句间停顿 1.5–2s，BGM 全程覆盖，交付前 silencedetect 验证无 ≥2.5s 无声段；
8. **开场直接进事件**：不加片头大标题，第一帧就是剧情画面；**剧名只出现在底部居中一个位置**（0s→正片结束常驻贴片，落版同位置衔接）；
9. **交付后提醒用户保留原始素材**：烧录在成片里的问题擦不掉，没有原始素材就只能裁补、无法重建。

## 一、Stage 1 素材接收与勘察

### 1.1 目录盘点
拿到素材先列全目录，确认齐全度：

| 素材 | 用途 | 说明 |
| --- | --- | --- |
| 成片（带硬字幕） | 拼接条唯一画面来源 | 如 18 集 1080×1920 H.264 |
| 无字幕成片 | 解说条画面来源 | 与成片时间轴一致 |
| BGM/音效 | 解说条垫乐 | 与集数对应；缺失时用软垫乐兜底（见 4.3） |
| 字幕 SRT | 选段定位 + 剧情分析 | 无 SRT 时用转录/wav 对齐兜底 |

另需：品牌 logo（透明底 PNG 优先）、剧名（中文+画面英文）、剪辑师缩写、剧代号。

### 1.2 规格勘察（ffprobe 逐条）
- 分辨率 / 编码 / fps / 时长 / 码率；
- **抽帧验证**（每集 ≥3 帧）：①有无烧录硬字幕；②有无 logo/贴片；③画面类型（真人/AI）。

### 1.3 字幕 → Cue 表 → 剧情地图
把 SRT 解析成「序号 [入点-出点] 台词」cue 表，通读标注：剧情弧线、**付费卡点位置**（钩子卡在其前一秒）、名场面清单（按情绪强度排序）。

> 工具要点：SRT 时间轴 `00:00:05,360` 逗号毫秒，解析时先把 `,` 换成 `.`。

## 三、Stage 3 选段规划（核心环节）

### 3.1 类型策略
**默认全部只做「多集串联拼接 + 跳剪」**；高光混剪/高光前置/二创解说仅在用户当次明确要求时制作（制作要点见下表对应行）。

| 类型 | 结构 | 选段特征 |
| --- | --- | --- |
| 多集串联拼接（默认） | A集悬念 → B集发展 → 钩子 | 每集 1–2 段，段间 2–8s |
| 单个高潮 | 一场完整高潮戏压缩 | 集中在同一集连续节点 |
| 高光混剪 | 名场面集锦 | 段最短（1.5–4s），节奏最快 |
| 高光前置拼接 | 最炸画面放第 1 段 → 倒叙 | 第 1 段必须自带冲击力；命名时高光集数单拎在最前 |
| 二创解说 | 解说(抓手) + 原片(身子) + 钩子 | 见 3.4/3.5 |

**每集覆盖**：规划完成后核对已用集数集合 = `all_episodes`，缺哪集就在哪集补选段（audit/pipeline 渲染前强校验，缺集 exit 3）。

### 3.2 镜头边界检测（跳剪质量的关键）

```
ffmpeg -i 第NN集.mp4 -vf "select='gt(scene,0.30)',showinfo" -f null - 2>&1 \
  | grep -o "pts_time:[0-9.]*" | cut -d: -f2 > epNN.txt
```

- 阈值 0.30 适用于真人剧；AI 剧可降 0.15；
- 解析认准 `pts_time:` 前缀；
- 选段入出点一律吸附最近切点。

### 3.3 全局去重审计（编码前强制）
全部选段汇成一个列表，两两检测（同集 + 时间区间重叠），**0 重叠 + 每集覆盖通过才准开渲染**。
实战数据：OAEN2457 项目 138 段 0 重叠；phmf 项目 238 段 / 1178.3s 独特画面（利用率 74%）0 重叠。

### 3.4 解说逐句对位
- 每句解说 → 一个专属选段，起点 = 该句描述的场景起点；
- 顺序游标排程：`下一句起点 = max(上一句结束 + 0.3s, 本选段起点 + 0.3s)`，**永不重叠**；
- 密度硬指标：每段画面 = 语音时长 + 1.5–2s 停顿；约 2 分钟解说条 26–30 句，插句优先填句间大空档；CTA 句强制置尾（字幕在落版前截断）；
- 多条解说共享素材池时**联合分配**：共享占用表 + 原始段预登记 + 按条顺序圈地。

### 3.5 解说词写作模板（英语三段式）
- 0–6s 抓手：身份反差 + 悬念钩子；
- 身子：虐点 → 爆点 → 爽点，每 20–30s 一个情绪峰值；
- 钩子/CTA：卡付费卡点，收尾引导（"Watch the ending on SODA TV"）。

## 四、Stage 4 界面元素与配音制作

### 4.1 PIL 生成元素（gen_assets.py，720×1280 基准）
1. **圆角 logo 贴片**：右上角，带轻微投影，全程显示；
2. **底部居中剧名贴片（title_banner.png）**：白色粗斜体 + 深色描边 + 金色下划线、透明底，`y=画面底-贴片高-30`，**0s 起常驻至正片结束**；字号自适应（文字宽 ≤ 画面宽-80px）；**不生成、不叠加任何片头大标题**；
3. **落版片尾**（3s 静态图）：大 logo + 搜索框 + App Store / Google Play 按钮 + 引导语 + 底部剧名（与贴片同位置衔接）。
   - 必须不透明深色底；必须静态图（动态按钮/指针有拒审风险）。

### 4.2 Edge 神经语音配音（edge-tts）
- 声线：`en-US-AvaNeural`（女）/ `en-US-AndrewNeural`（男）；语速 `+8%`；语种必须与原片一致；
- 逐句生成，同步记录 durations.json；
- 避坑：Windows SAPI（Zira）机器感重、吐字含混，不用于成片；多句配音严禁固定偏移排程。

### 4.3 BGM 缺失兜底
用同工作流产出的软垫乐（如 phmf 项目 `bgm_soft.wav`：140s、44.1k 立体声、mean -14dB）；要求时长 ≥ 片长 + 10s；增益 0.14；交付清单注明替换。

## 五、Stage 5 ffmpeg 批量构建（build_clip.py / pipeline.py）

### 5.1 视频链（每条素材）
```
选段 trim → scale=720:1280 → overlay(logo 全程) →
overlay(底部剧名贴片 0s→正片结束) → [解说条: subtitles=ASS] →
concat(正片) → concat(落版3s) → libx264 + AAC 160k
```
**无片头大标题叠加**。视频输入索引：logo=nvid、banner=nvid+1、endcard=nvid+2、aux 从 nvid+3 起——增删 overlay 输入后必须同步 i_ec/i_aux0（错位一格=滤镜图挂掉或贴错素材）。

### 5.2 音频链
- 拼接条：选段原声直通（音画同步是底线）+ 落版 BGM；
- 解说条：`解说 ×1.35（adelay 按排程）` + `BGM ×0.13–0.16（afade in/out）` amix；
- **BGM 时长 ≥ 成片时长**：构建链用 atrim 截断垫乐，BGM 偏短则片尾整段无声；
- 解说条直接不用原片对白（三层人声必糊）。

### 5.3 环境与版本坑
- ffmpeg 9.0.2（imageio_ffmpeg 自带，**只有 ffmpeg 没有 ffprobe**，时长用 `ffmpeg -i` 的 Duration 行解析）；
- ffmpeg 9 移除 `-filter_complex_script`，用 `-/filter_complex 文件` 或内联；
- 滤镜清单（构建前验证）：libx264 / subtitles(ass) / delogo / amix / adelay / volumedetect / silencedetect；
- build_clip 输出名 = clips key + `.mp4`：**key 不要带 .mp4**（脚本已兼容剥除，但规范不带）。

### 5.4 码率达标
- CRF 19 ≈2600–3000kbps，CRF 18 ≈2700–3200kbps；默认 19，pipeline 码率不足自动降 2 重试；
- 严禁 <2500kbps 交付。

## 六、Stage 6 五维质检（全部 PASS 才算完成）

| 维度 | 工具 | 达标线 |
| --- | --- | --- |
| 规格 | ffprobe/ffmpeg -i | 720×1280 / H.264 / 30fps / ≥2500kbps / AAC |
| 电平 | volumedetect | 峰值 -1.5 ~ -3dB，无削波 |
| 静音 | silencedetect(-30dB,2.5s) | **≥2.5s 无声段 = 0** |
| 音频内容 | AudioTranscribe | 解说逐句清晰、顺序正确、无重叠；同路径疑缓存，改名切片复验 |
| 画面 | 定点抽帧(1s/中段/落版) | ①head 帧无中央大标题且有底部剧名贴片；②贴片全程居中不遮 logo 不压字幕；③解说字幕框内不超边；④落版无双重剧名；⑤无黑帧 |
| 命名 | 对照九段式+集数规则 | 见 spec.md，集数与实际用集逐一核对 |

## 七、Stage 7 命名与交付

- 九段式：`YYYYMMDD_序号_中文剧名_剧代号_集数_素材分类_素材时长_缩写_自定义项`；
- 集数写法（细节见 spec.md）：连续集数部分片段用 `--`（1--4、9--14），非连续用 `-`（2-5-7），单集 `7-7`，高光前置集数单拎最前（16-1--3-5--6）；**集数必须与实际用集一致**；
- 素材时长按分钟向下取整；跳剪写自定义项、混剪写素材分类（二选一）；
- 单文件 >500M：压素材本身，不压打包；
- 附《交付清单.md》：集数来源/类型/钩子卡点/时长码率速查表 + 修订记录 + 待确认事项；
- **交付说明中提醒用户保留原始素材目录**。

## 八、踩坑记录（实战发生的问题与对策）

| # | 现象 | 根因 | 对策 |
| --- | --- | --- | --- |
| 1 | 解说音频糊成一片 | 解说+对白+BGM 三层人声打架 | 解说条去掉对白轨，只留解说+BGM |
| 2 | 解说前后句互相压上 | 固定偏移排程 | 顺序游标排程，程序验证 0 重叠 |
| 3 | TTS 吐字含混错读 | Windows SAPI 质量差 | 换 edge-tts 神经语音 |
| 4 | 多条素材画面大量重复 | 未做全局查重 | 镜头检测 + 全局唯一审计 + 2–8s 短段 |
| 5 | 解说字幕超出画面 | 字号 46 + 每行 44 字符 | 40 号 + 每行 28 字符 |
| 6 | 落版与结尾字幕重叠 | outro 字幕压落版 | 字幕在落版前截断 |
| 7 | 码率不达标 | CRF 20 偏高 | 默认 19，不足自动降 18 重试 |
| 8 | ffmpeg 9 报未知选项 | `-filter_complex_script` 已移除 | 改 `-/filter_complex` |
| 9 | 场景检测提取不到切点 | showinfo 解析错误 | 认准 `pts_time:` 前缀 |
| 10 | 解说片中段十几秒纯无声 | BGM 短于片长被截断 + 停顿过长 | BGM ≥ 片长+10s；停顿 ≤2s；silencedetect 复验 |
| 11 | 解说句子错音/张冠李戴 | durations.json file 映射被旧状态污染 | 校验映射唯一有序；按文本匹配音频 |
| 12 | 解说条之间撞段 | 占用表漏算其它解说条 | 联合分配 + 原始段预登记 |
| 13 | 转录复核与旧版雷同 | AudioTranscribe 同路径疑缓存 | 改名切片转录复验 |
| 14 | **剧代号写错整批返工** | 开工未问，沿用历史代号 TK | 剧代号必问；Stage 2 一次问齐 |
| 15 | **集数标注与实际用集不符**（多写未用集/连续段未用 `--`/高光集未单拎） | 命名时未逐条核对选段清单 | 命名前逐条核对实际用集；连续部分片段用 `--`；高光集单拎最前 |
| 16 | **片头大标题被要求去除**（素材开头要直接进事件） | 默认加了 0–4s 剧名大标题 | 已废除片头大标题；剧名只走底部贴片 0s 常驻 |
| 17 | **剧名出现位置不统一**（片头中央/底部/落版三处） | 未定义唯一位置 | 剧名唯一位置=底部居中；落版同位置衔接；抽帧复核 |
| 18 | 重建时输出文件双 `.mp4` 扩展名 | project.json key 带了 .mp4 | key 不带扩展名；脚本自动剥除兜底 |
| 19 | 滤镜图报 "matches no streams" | 去掉 title 输入后 i_ec/i_aux0 未同步，索引错位一格 | 增删 overlay 输入必须同步全部输入索引（见 5.1） |
| 20 | 原始素材被移走，烧录问题无法修复 | 交付后用户移动/删除素材 | 交付时提醒保留；就地修补三招（裁头/叠贴片/重建）按 8.x 判断 |
| 21 | 就地裁头后首段只剩 0.1s 闪帧 | 裁点落在首段末尾 | 裁点避开短首段：必要时裁掉整段；裁点不得切断解说句 |
| 22 | ffprobe 不存在 | imageio_ffmpeg 只带 ffmpeg | 用 `ffmpeg -i` 的 Duration 行正则解析时长 |

## 十、单条素材工时参考（熟练后）

勘察建档 0.5h → 选段规划 1h → 元素制作 0.5h（一次制作全批复用）→ 配音 5min → 构建 2min/条 → 质检 10min/批 → 命名交付 15min。
**10 条素材全程约 2.5–3 小时**（含审计与返工缓冲）。
