# 投流素材硬性规范速查（源自《投流素材培训（202606）》，制作与命名必须遵守）

## 输出规格
- 画幅 9:16，分辨率 720×1280；编码 H.264；30fps。
- 码率：剪映导出 ≥1000+，PR 比特率 3–5，**成片视频码率 ≥2500kbps**（不足就降 CRF 重编码）。
- 音频 AAC 160kbps / 44.1kHz。
- 单文件 >500MB：压缩素材本身（保持 720p/1080p、比特率 2500+kbps），不压打包文件。

## 九段式命名（强制，写错整批返工）
`时间_素材序号_中文剧名_剧代号_集数_素材分类_素材时长_剪辑师缩写_自定义项`
- 时间：8 位日期，如 `20261113`；
- 中文剧名：严格按任务表；剧代号：**必须问用户**（如 OAEN2457），严禁假设或沿用历史代号；
- 集数：连续集数中的部分片段用 `--`（如 `1--4`、`9--14`），非连续集数用 `-` 分隔（如 `2-5-7`），混合时连写（如 `2-5-7--10` = 第2、5集部分 + 第7到10集），单集写 `7-7`，无集数概念写 `0`；
  - **集数必须与实际用集一致**：命名前逐条核对选段清单的实际集数集合，多写未用集、漏写已用集都算错；
- 高光前置：高光集数**单拎在主体最前**（如主体 5--13、高光取自第 7 集 → `7-5--13`）；高光若是主体首集内容则不单拎，直接写 `5--13`；
- 素材分类：拼接 / 解说拼接 / 高光混剪 / 高光前置拼接 等；**默认只交付「拼接」类（跳剪），其余类型仅在用户明确要求时制作**；
- 素材时长：按分钟**向下取整**（85s 写 1）；
- 自定义项：无内容填 `0`。
- **二选一铁律**：单集/拼接只选其一；跳剪（写自定义项）与混剪（写素材分类）只选其一。

## 界面必备元素（每条素材）
- 品牌 logo 贴片（圆角，右上/左上角，全程显示）；
- **开场直接进剧情事件（钩子前置），不加片头大标题贴片**（2026-11-13 用户规则：素材开头直接用事件抓注意力）；
- **剧名唯一常驻位置 = 底部居中贴片（2026-11-13 用户规则）**：白色粗斜体 + 深色描边 + 金色下划线、透明底，`y=画面底-贴片高-30`，**0s 起常驻至正片结束**；落版自带剧名同在底部居中衔接——剧名从头到尾只出现在底部这一个地方；不得遮挡右上 logo、不得压原片字幕/解说字幕；
- 3s 落版片尾：大 logo + 品牌搜索框 + App Store / Google Play 按钮 + 引导语 + 剧名（与底部贴片同位置衔接）。
  - 落版必须**不透明深色底**；必须**静态图**（动态按钮/点击指针有拒审风险）。

## 原片拼接规范
- 结构：抓手（前 6 秒）+ 身子 + 钩子；三大定律：前 6 秒抓人、每 45 秒一个情绪峰值、损失厌恶。
- 钩子卡在高潮/反转前一秒，或直接卡付费卡点。
- 原片拼接占比约 65%，允许跳剪；跳剪切点必须落在镜头边界。
- 保留原片烧录字幕与原声（音画同步是底线）。

## 二创解说规范
- 结构：解说（抓手）+ 原片拼接（身子 + 钩子）。
- 命名集数：解说类型只写原片拼接的集数；混剪类型用哪些集数写哪些。
- 解说配音语种必须与原片语种一致（英语剧配英语解说）。
- 必配 BGM；垫乐音量不得压过解说；**严禁解说、原片对白、BGM 三层人声同响**。
- 使用无字幕成片作画面（无字幕成片不可得时，须遮挡/模糊原片硬字幕）。
- 解说字幕：烧录，白字黑边，位于画面下方约三分之一上沿，每行 ≤28 字符、最多 3 行，不得超出画面。
- 解说排程：上一句说完 ≥0.3s 才起下一句，永不重叠；结尾 CTA 句可压落版，但字幕须在落版前截断。

## 优先级与协作
- 英语素材高于小语种；英语档期变更须沟通，小语种可自行调整。
- 上线前对照「素材违规拒审点」过一遍：擦边尺度、版权画面、静态落版、无诱导点击动画。

## 工艺参数速查（本工作流验证值）
| 参数 | 值 |
| --- | --- |
| 场景切换检测阈值 | 0.30（真人剧）/ 0.15（AI 剧） |
| 跳剪选段长度 | 2–8 秒/段，切点吸附镜头边界 |
| 解说增益 | 1.35；原片对白底 ≤0.15 或直接不用；BGM 0.11–0.14 |
| 目标电平 | 峰值 -1.5 ~ -3dB |
| CRF | 默认 19（≈2600–3000kbps），码率不足降 18 |
| 解说句间隔 | ≥0.3s，句间永不重叠 |
| 字幕样式 | Arial 40（720×1280 基准，随高度缩放），Outline=3，MarginV=380 |
